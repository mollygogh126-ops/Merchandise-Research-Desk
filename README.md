# Merchandise-Research-Desk

Merchandise-Research-Desk is a small private work tool prepared for our internal product study. Its purpose is to help our team look at visible product information on Etsy and better understand general market directions before developing new items.

The project connects with the Etsy Open API to consult information already public on Etsy, including item names, shown prices, keywords, materials, product photos, and basic shop details.

# Main Use

This application is only for our company’s internal reference. It is not made for public users, it has no paid access, and it is not used to publish, update, manage, or remove Etsy listings.

# Information Consulted

The tool works in read-only mode and only requests public listing information. It does not collect private seller details, payment information, order records, customer conversations, or any confidential account data.

# Development Stage

This project is still being tested and improved. The API features may change depending on Etsy’s approval process, technical limits, and permitted access scope.
